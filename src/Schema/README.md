# MCP Schema

The types of the [Model Context Protocol](https://modelcontextprotocol.io): requests, results, notifications, content
and capabilities as immutable PHP value objects, plus the JSON-RPC layer that parses and serializes them.

`mcp/client` and `mcp/server` build on this package. Install it on its own only if you work with MCP messages
directly.

```bash
composer require mcp/schema
```
